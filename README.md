# 不止想想 · Curious at Heart.

六水的个人创作手账，记录好奇、行动、内容实践与日常生活。

## 页面

- **首页 `/`**：翻书式个人手账，九个章节。可通过按钮、目录或键盘左右方向键翻页。
- **作品集 `/?view=career`**：保留原来的求职作品集、完整项目与证据；不删除既有项目。
- 核心表达：70% 用户洞察、商业思考、项目成果、内容分析与复盘；30% 个人气质与生活。
- 不再把同龄人、长辈、付费客户的三种观察视角写到公开自我介绍中；该分析只用于筛选内容侧重点。
- 从本人 X、朋友圈、Flomo 原文以及现有项目记录整理案例。公开文案经过筛选，不包含私密家庭细节或咨询客户的私密文档。
- 访谈学习笔记有明确标注，不将他人的营销观点冒充个人原创理论；不同数据保留证据与口径说明。

## 开发与部署

```bash
npm install
npm run dev
npm run build
```

技术栈：React + TypeScript + Vite，沿用原有 Vercel 部署。

## 图片

仍引用仓库 `public/images` 中现有的图片；**本次没有使用 AI 生成、修复或修改任何照片文件**。仅通过网页的 CSS 完成响应式排版。需要替换照片时，应使用用户确认的原图。

## 文字与数据说明

- Flomo 导出时间为 2026 年 7 月，含 640 条 Memo；首页展示“640+”，仅表示该导出时点已有的积累。
- 游泳：2024 年 6 月的朋友圈记录描述从不到 10 米到自学自由泳 1.5 公里；2025 年 4 月又记录了自由泳 1000 米在半小时内完成。
- 其他内容播放量和项目数字见原求职作品集，且区分本人记录与公开截图可验证的数据。
- 个人社交平台上的句子以原话节选呈现，匿名处理其他人的私密信息。
