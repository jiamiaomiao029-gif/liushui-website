## 本地预览

在完整仓库中打开 `previews/curious-at-heart-v2.2/index.html`，或把整个 `curious-at-heart-v2.2/` 文件夹复制出来打开 `index.html`。照片需要和 HTML 一起保留在 `images/` 子目录内。

网页中的「替换原始照片」提供临时本机预览。它不会上传图片，也不会在刷新后保存。正式公开前应复核原图授权与个人隐私。
