## 替换自己的原始照片（两种方式）

### 立即预览（最简单）

1. 打开 `index.html`。
2. 滚动到下方 **「替换原始照片」**，点击展开。
3. 为五章各自选择 JPG、PNG、WEBP 原始图片，书中会立即更新。
4. 项目证据在两张案例卡片里的「展开项目过程与证据」里选择对应原图。

这些预览使用浏览器本地的 Object URL，不上传网络，不进行 AI 处理。**刷新后不会保存**。

### 永久保存到离线网站

1. 把原始照片复制到 `images/` 文件夹，例如 `images/01-about.jpg`。
2. 在 `index.html` 中搜索 `const chapters = [`，找到相应章节的 `image:''`。
3. 例如修改为 `image:'images/01-about.jpg'`。其余章节以此类推。
4. 图片在书页用 `object-fit:cover` 排版裁切，不会修改文件内容；如果要完整保留画面，可将 `.photo-holder img` 的 `object-fit:cover` 改为 `object-fit:contain`。

案例证据目前仅支持本机预览。后续最终发布版应将经过隐私处理的证据图片放进固定资源目录，并改为实际文件引用。
